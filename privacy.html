Privacy

Privacy by default.

The TaxRoot calculator works in the browser and these standalone pages do not include account creation, server-side submission, or stored tax profiles.

Current privacy baseline

  • No sign-up flow.
  • No built-in profile creation.
  • No server-backed tax history in this standalone implementation.

Local calculation

Input values are processed in JavaScript inside the page. Nothing in this static version is set up to send your tax numbers to a backend.

Minimal data use

  • No sign-in flow.
  • No personal profile creation.
  • No built-in tracking of calculator entries.

Important note

If analytics, storage, or form submission are added later, this privacy page should be updated to match that new behavior.

This privacy page describes the current standalone front-end behavior only.
